# 各平台逐項設定清單

> 讀這份的時機：正在實際操作某個平台，需要逐項打勾與可直接複製的文案。
> 範例值取自「時空擂台」專案，實作時替換成你的品牌資訊。

---

## YouTube

### A. 建立
1. 用**品牌信箱**登入 Google → `youtube.com` → 建立頻道
2. 建議建在**品牌帳號**下（Google 帳號可管理多個品牌帳號）：
   `myaccount.google.com/brandaccounts` → 建立 → 命名 → 切換
3. 進入 `studio.youtube.com`，確認右上頭像顯示的是目標頻道

### B. 品牌視覺（自訂 → 個人資料）
| 項目 | 值 |
|------|-----|
| 橫幅圖片 | 2048×1152 PNG（重點字在中央 1235×338 內） |
| 顯示圖片 | 800×800 PNG，圓形裁切 |
| 浮水印 | 150×150 PNG，顯示「整部影片」 |

### C. 基本資訊
- 名稱：品牌名（例：時空擂台）
- 帳號代碼：`@<handle>`（例：shikongletai）
- 國家／地區：台灣
- 關鍵字：15 個以內，涵蓋主題、人物、形式（例：歷史、饒舌、AI動畫、名人對決…）

### D. 說明欄（可複製改寫）
```
🎤 AI 讓歷史人物開口饒舌，把課本裡的古人變成最會 diss 的對手。

每週一場跨時空對決：秦始皇 vs 凱薩、孔子 vs 蘇格拉底、李白 vs 莎士比亞……
你判誰贏？留言指定下一場！

#歷史饒舌 #名人對決 #AI動畫 #課本沒教

訂閱時空擂台 → https://www.youtube.com/@<handle>
```
多語：設定 → 頻道 → 語言 → 新增翻譯（簡中／英文各一版）

### E. 上傳預設值（設定 → 上傳預設值）
- 標題／說明模板（含 hashtag 與訂閱連結）
- 標籤 5 個
- 預設可見度：不公開（檢查後再改公開）

### F. 社群（設定 → 社群）
- 留言：改為「保留可能不適當的留言以供審查」
- 封鎖字詞 10 組
- 含有連結的留言先送審

### G. 播放清單（第一支影片上傳時建立）
1. 歷史對決全集　2. AI 製作幕後　3. Shorts

## Instagram

1. 註冊／登入 → 確認**目前帳號**（右上或左下切換帳號）
2. 個人檔案 → 編輯個人檔案：
   - 名稱：品牌名
   - 使用者名稱：`<handle>`
   - 網站：YouTube 頻道連結
   - 個人簡介（150 字內，範例）：
     ```
     AI 讓歷史人物開口饒舌｜每週一場跨時空對決｜秦始皇 vs 凱薩、孔子 vs 蘇格拉底……
     你判誰贏？留言指定下一場 👇
     #歷史饒舌 #AI動畫 #名人對決
     ```
3. 大頭貼：`accounts/edit` → 對隱藏的 `input[type=file]` 直接 `setInputFiles('<logo.png>')` → 套用 → 儲存
4. 檢查：`instagram.com/<handle>/` 公開頁面確認頭像、名稱、bio

## TikTok

### A. 註冊（手機 App）
1. 登出既有帳號 → 註冊 → **使用電子郵件**（不要電話，除非該號碼沒綁過）
2. 生日 ≥18 歲、品牌信箱、密碼
3. 圖形驗證 → 收 6 位數驗證碼 → 完成
4. 建議用 4G/5G 註冊，同一個 WiFi IP 短時間多次註冊會被鎖

### B. 個人資料
| 項目 | 限制 |
|------|------|
| 使用者名稱 | 30 天只能改一次 |
| 暱稱 | 7 天只能改一次 |
| 個人簡介 | 80 字（含換行與 emoji） |
| 網站 | 只有商業帳號有；個人帳號請把連結寫進 bio 文字 |

80 字 bio 範例（79 字）：
```
AI 讓歷史人物開口饒舌｜每週跨時空對決｜秦始皇 vs 凱薩
你判誰贏？留言指定下一場
#歷史饒舌 #AI動畫
▶ YouTube：@<handle>
```

### C. 商業帳號
- App：個人檔案 → ≡ → 設定與隱私 → 帳號 → 切換為商業帳號 → 選類別（娛樂／教育）
- 可能需要身份或營業驗證；過不了就留在個人帳號
- 代價：只能用商用音樂庫，熱門流行歌不能用

### D. 驗證
`tiktok.com/@<handle>` → 確認暱稱、bio、頭像；`找不到此帳號` 表示 handle 沒設成功或還在冷卻

## 三平台一致性檢查表（影印用）

```
[ ] 顯示名稱一致
[ ] handle 一致（@xxx）
[ ] 頭像同一張
[ ] 簡介主句一致
[ ] 導流連結都存在且可點（或至少可讀）
[ ] 分類／關鍵字合理
[ ] 全部用「公開頁面」看過一次
```
